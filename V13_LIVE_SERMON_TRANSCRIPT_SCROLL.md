# Version 13 — Live Sermon Transcript Scroll

This release changes only the Live Sermon Translation transcript presentation.

- Transcript order is oldest to newest.
- The newest translated sentence is the last line and is bold.
- Each new sentence pushes the previous sentence upward.
- The transcript automatically scrolls to keep the newest line visible.
- The transcript area has a mobile-friendly maximum height and its own vertical scrolling.
- Danish, English, and Urdu language handling is unchanged.
- Shared Christian vocabulary, learned vocabulary, Bible Reading, Daily Devotion, Hymnbook Editor, and Firebase logic are unchanged.
- No Firebase deployment is required for this change.
