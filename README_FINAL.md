# One in Christ Church — final Android source baseline

Packaged 24 September 2026, after the English, Danish, and Urdu language reviews.
This is the current source project for continued maintenance and future iPhone work.
It is not an APK or an iPhone release.

## Included

- App source, public assets and complete hymnbook
- Android native source and Gradle wrapper
- Firebase Functions, security rules, project configuration and dependency lockfiles
- Language corrections, regression tests, TYPO3 integration and setup guides
- Older release notes under `docs/history` for reference only

## Clean package

Installed dependencies, web output, Android build output/caches, generated Capacitor
assets, IDE state, local SDK paths, logs and signing keys are excluded. These are
not required source files. The working installation has not been stripped of its
dependencies or machine configuration. No source features or hymnbook content
were removed, and no backend deployment was performed during packaging.

## Restore and build on Windows

Extract the archive into a new folder. From that folder, run each command in order
and stop if a command fails:

```powershell
npm.cmd ci
npm.cmd --prefix functions ci
node --experimental-vm-modules --test tests/*.test.mjs
npm.cmd run build
npx.cmd cap sync android
npx.cmd cap open android
```

Use Node 22 for the backend as declared in `functions/package.json`. Android Studio
must have a suitable JDK and Android SDK configured. Select your connected phone
and Run. Updating an existing signed release requires its original signing key;
signing keys are not included in this archive.

For later backend releases, run from the project root:

```powershell
$env:FUNCTIONS_DISCOVERY_TIMEOUT = "60"
npx.cmd firebase-tools deploy --only functions --project one-in-christ-church
```

The latest language updates are documented in `LANGUAGE_QUALITY_UPDATE.md`.
Existing saved devotions are not regenerated by deployment. Bible-source text
is preserved. Automated language checks cannot guarantee perfect live translation.

## iPhone handoff

The current project has no iOS platform folder. Use a Mac with Xcode for the next
development phase; `IOS_SETUP.md` contains the existing handoff notes. iOS plugin
installation, Firebase configuration, signing and device testing still need work.

## Integrity

`RELEASE_MANIFEST.json` records the SHA-256 hash of every packaged project file.
The adjacent `.zip.sha256` file records the archive hash. Tests passed before
packaging; this cleanup did not build a new signed APK.
