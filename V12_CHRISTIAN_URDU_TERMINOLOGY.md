# Version 12 - Christian Urdu Terminology Guardrails

Version 12 keeps Version 11's six-month Bible Reading no-repeat rule and strengthens the existing shared church vocabulary for generated/translated Urdu content.

## Applies to
- Live Sermon Translation when Urdu is the target language
- Daily Devotion generated explanation, application, and prayer
- Bible Reading generated reflection and questions

## Does not apply to
- Scripture Preparation Bible text
- Bible Reading Bible-source verse text
- Any Bible verse text returned directly by the configured Bible source

## Key Christian Urdu corrections
- حضرت عیسیٰ / عیسیٰ -> یسوع / یسوع مسیح according to context
- حضور یسوع -> خداوند یسوع
- اسلامی honorific علیہ السلام is removed from generated Christian content
- Holy Spirit -> روح القدس
- Church -> کلیسیا
- Lord Jesus Christ -> خداوند یسوع مسیح

The permanent core Christian vocabulary is applied after learned vocabulary as a final guardrail, so learned entries can extend terminology without overriding protected Christian wording.
